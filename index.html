How a request moves

  1. Submitted

    You describe the problem and add a photo if it helps. Administrators are alerted straight away.

  2. Assigned

    An administrator sets the priority and sends it to the right technician.

  3. In progress

    The technician updates the status and leaves notes. You get a notification for every change.

  4. Resolved

    Check the fix and rate the service so the team can see what needs to improve.

Response targets

Every request gets a deadline based on its priority. Requests that pass it are flagged for administrators, so nothing quietly gets forgotten.
